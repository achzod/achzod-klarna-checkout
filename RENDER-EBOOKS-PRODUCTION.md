# Render Ebook Downloads

## Render settings

Add a Persistent Disk to the `achzod-klarna-checkout` service:

- Mount path: `/var/data`
- Ebook directory: `/var/data/ebooks`
- Recommended size: 5 GB minimum, 10 GB if all source PDFs are kept large.

Environment variables:

```text
EBOOK_STORAGE_DIR=/var/data/ebooks
DOWNLOAD_TOKEN_SECRET=<long-random-secret>
DOWNLOAD_BASE_URL=https://achzod-klarna-checkout.onrender.com
DOWNLOAD_TOKEN_TTL_SECONDS=7776000
```

`DOWNLOAD_SIGNING_SECRET` is also accepted as a legacy alias for `DOWNLOAD_TOKEN_SECRET`.

## Files expected on disk

Upload the PDFs to the mounted disk with exactly these filenames:

```text
/var/data/ebooks/anabolic-code.pdf
/var/data/ebooks/potentiel-genetique.pdf
/var/data/ebooks/4-semaines-shred.pdf
/var/data/ebooks/bioenergetique-timing-nutrition.pdf
```

After upload, verify each file:

```bash
ls -lh /var/data/ebooks
shasum -a 256 /var/data/ebooks/*.pdf
```

## Smoke checks

The public health endpoint includes download readiness without exposing secrets:

```bash
curl https://achzod-klarna-checkout.onrender.com/health
```

Each paid ebook link is now generated by Render as:

```text
https://achzod-klarna-checkout.onrender.com/download/<slug>?token=<signed-token>
```

The client never receives a raw filesystem path or an external file-host URL.
